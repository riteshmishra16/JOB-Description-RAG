# Job Description RAG Assistant

A simple Retrieval-Augmented Generation (RAG) application that answers questions about job descriptions and required skills. It uses Sentence Transformers to create embeddings, FAISS to retrieve relevant documents, LangChain to connect the retrieval and generation steps, and Google Gemini to generate answers.

## Features

- Loads job-related data from Hugging Face Datasets.
- Converts job descriptions into LangChain `Document` objects with metadata.
- Splits documents into smaller chunks using `RecursiveCharacterTextSplitter`.
- Creates semantic embeddings with `sentence-transformers/all-MiniLM-L6-v2`.
- Retrieves relevant chunks using FAISS similarity search.
- Generates context-based answers using Google Gemini.
- Provides a FastAPI backend and a simple Streamlit interface.

This project uses the [Job Skill Set dataset](https://huggingface.co/datasets/batuhanmtl/job-skill-set) from Hugging Face.

## Setup

### 1. Create and activate a virtual environment (Windows PowerShell)

```powershell
python -m venv rag_venv
.\rag_venv\Scripts\Activate.ps1
```

### 2. Install dependencies

```powershell
python -m pip install -r requirements.txt
```

### 3. Configure the Google API key

Create a `.env` file in the same project folder as `app.py` and add your key:

```text
GOOGLE_API_KEY=your_google_api_key
```

### 4. Build the FAISS index

Open the notebook and run its cells in order: load the dataset, create `Document` objects, split them into chunks, create embeddings and the FAISS vector store, then save it using:

```python
vector_store.save_local("faiss_index")
```

The `faiss_index` folder must exist in the project directory before starting the backend. If the app loads an existing index, rebuild it after changing the documents or chunking settings.

## Run the Application

Open two terminals in the project folder.

### Terminal 1: FastAPI backend

```powershell
python -m uvicorn app:app --reload --host 127.0.0.1 --port 8000
```

API documentation: <http://127.0.0.1:8000/docs>

### Terminal 2: Streamlit frontend

```powershell
python -m streamlit run streamlit_app.py
```

Keep both terminals running while using the app locally.

## Example Questions

- What skills are required for a Data Scientist?
- What are the responsibilities of a Data Scientist?
- What skills are required for finance jobs?
- What technical skills are mentioned in the job descriptions?

Answers depend on the information available in the dataset and the chunks retrieved by FAISS. The application should not invent information that is absent from the retrieved context.

## Security Note

The app loads a locally saved FAISS index with `allow_dangerous_deserialization=True`. Only load an index that you created yourself or obtained from a trusted source.
